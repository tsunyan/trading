# USD/JPYを実践で使うための実装計画

開始日: 2026-10-03

目的は単一銘柄USD/JPYについて、定期観測から実口座の状態照合、明示的な発注、障害時の停止と
復旧までを実用可能にすることです。日本株と複数銘柄は後回しにします。
口座は未準備のため、実口座受入はコードと合成通信の検証を終えた後に実施します。
通知先はWindowsデスクトップです。キーをチャットに記載する運用にはしません。

研究上のcandidateから発注許可への自動変換を前提にしません。
現金会計・注文照合の未確認条件は発注前に明示し、確認できない場合は停止します。
