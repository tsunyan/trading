# 研究と観測の執行条件差

2026-10-05。ペーパー観測の約定を、研究のバックテストが同じ判断で想定する約定と比べる
読取専用のCLI`trading.execution_gap`を追加しました。ペーパーのDBは読取専用で開き、変更しません。

## 比べるもの

| | 約定の想定 |
| --- | --- |
| 研究（`execution_mode=bid_ask`） | 判断した足の次の足の始値。BID/ASKの中値に、観測スプレッド（設定の`spread`を下限）の半分と`slippage`を加減 |
| ペーパー観測 | 判断した足が閉じた後に取得した公開気配のASK（買い）またはBID（売り）に`slippage`を加減 |

ペーパーの`signal_time`は直前の確定足の終了時刻で、研究が約定する足の開始時刻と同じです。
約定ごとに次を出します。

- `cost_pips`・`cost_jpy`: ペーパーの約定が研究より口座に不利だった幅。正なら研究が楽観的です。
- `quote_delay_seconds`: 足の開始から、ペーパーが使った気配までの秒数。
- `paper_spread_pips`・`research_open_spread_pips`: それぞれの時点のスプレッド。

研究の足がない約定は`missing_research_bars`に出し、推測で埋めません。
`sufficient_sample`は比較できた約定が30件以上かどうかです。それ未満では傾向を判断しません。

## 使い方

```powershell
uv run python -m trading.execution_gap --directory runs/paper-sma-24-120-observation --output runs/execution-gap.json
```

足は観測ディレクトリの`candles/`（確定した取引日だけをキャッシュ）から読みます。
当日など未キャッシュの期間は、`fetch-fx`で取得したファイルを`--bars`で追加します。

## 2026-10-05時点の結果

SMA 24/120の探索観測の約定は1件（2026-10-01 11:00 UTCの買い2,529通貨）でした。
ペーパーは足の開始から57秒後の気配で約定し、研究の想定より2.05 pips（51.84円）有利でした。
1件だけなので、研究の約定想定が楽観的か保守的かはまだ判断できません。

## 限界

- 研究の約定は足の始値のBID/ASKで、始値の瞬間に約定できたとは限りません。ペーパーも公開気配での
  仮定約定で、実口座の約定とは違います。実口座の差は[損益レポート](live-report.md)のスリッページで測ります。
- 手数料・スワップは比べません。両者で同じ設定を使うためです。

検証: `tests/test_execution_gap.py`（売買の符号、研究の足がない場合、BID/ASK列の必須、CLIがDBを変えないこと）。
